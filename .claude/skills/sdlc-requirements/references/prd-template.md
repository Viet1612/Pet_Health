# Khung PRD

```markdown
# Tài liệu Yêu cầu Sản phẩm (PRD) — <Tên sản phẩm>

| Thuộc tính  | Giá trị       |
| ----------- | ------------- |
| Mã tài liệu | <PRJ>-PRD-001 |
| Phiên bản   | 1.0           |
| Ngày        | YYYY-MM-DD    |
| Trạng thái  | Draft         |
| Nguồn       | BRD v<x>      |

## 0. Kiểm tra đầu vào (Product pillars validation)

Bảng: Trụ cột (vấn đề, người dùng, giá trị, phạm vi, chỉ số) | Có trong BRD? | Ghi chú / giả định.

## 1. Tóm tắt điều hành và chiến lược

- Vấn đề, giải pháp, khác biệt, mục tiêu đo được (OKR/KPI), phạm vi MVP vs sau MVP.

## 2. Persona và hành trình người dùng

### 2.1 Persona — bảng: tên, mô tả, mục tiêu, nỗi đau, tần suất dùng, thiết bị.

### 2.2 Hành trình chính — các bước, cảm xúc, cơ hội.

## 3. Yêu cầu chức năng và User Stories

### E1 — <Epic>

| ID     | User story                                      | Ưu tiên (MoSCoW) | Truy vết BR |
| ------ | ----------------------------------------------- | ---------------- | ----------- |
| US-001 | Là <persona>, tôi muốn <hành động> để <giá trị> | Must             | BR-001      |

**Tiêu chí chấp nhận US-001**

- **Given** … **When** … **Then** …
- (case lỗi, case biên)

## 4. Yêu cầu UX và UI

| ID                                          | Yêu cầu                    |
| ------------------------------------------- | -------------------------- |
| UXD-001                                     | Mobile-first, breakpoint … |
| UXD-002                                     | WCAG 2.2 AA …              |
| Danh sách màn hình chính dự kiến (SCR-01…). |

## 5. Tiêu chí phát hành và chỉ số sau ra mắt

| Gate                                        | Điều kiện                | Cách đo      |
| ------------------------------------------- | ------------------------ | ------------ |
| G-1                                         | 100 % US Must có AC Pass | báo cáo test |
| Chỉ số sau ra mắt: activation, retention, … |

## 6. Truy vết BRD → PRD

| BR | US | Ghi chú |

## 7. Quyết định và câu hỏi mở

| ID | Câu hỏi / quyết định | Người quyết | Ngày | Trạng thái |

## Lịch sử thay đổi

| Phiên bản | Ngày | Thay đổi |
```
